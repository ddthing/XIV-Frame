# XIV Frame

XIV Frame은 파이널판타지14(FF14) 스크린샷을 구성하고 PNG·JPEG 또는 편집 가능한 프로젝트로 저장하는 브라우저 스튜디오입니다.

## 주요 기능

- **사진 배열과 정밀 편집**: 최대 4장의 스크린샷을 가로·세로·바둑판 프레임에 배치합니다. 사진별 크기, 위치, 순서와 위치 잠금을 지원합니다.
- **스튜디오 프리셋**: 갤러리·시네마·포트레이트의 비율, 배열, 여백을 한 번에 적용합니다. 자동·16:9·2:1·1:1·4:5·9:16 비율을 지원합니다.
- **편집 이력**: 사진 추가·삭제·교체, 변형, 프리셋, 시그니처, 초기화를 최대 50단계까지 되돌립니다. 연속 조정은 묶어서 기록하며 화면 확대는 이력에 포함하지 않습니다.
- **시그니처와 합성**: 캐릭터 이름·서버명·글꼴·정렬·로고를 설정하고, 캐릭터 배경 제거와 브러시 보정을 사용할 수 있습니다.
- **작업 이어하기**: `.xivframe` 파일에 사진·로고·합성 이미지와 편집 설정을 함께 저장합니다. 다른 세션에서 열어 편집할 수 있고, 가져오기도 실행 취소가 가능합니다. 프로젝트는 최대 80MB이며 가져오기 검증이 실패하면 기존 작업을 유지합니다.
- **출력 설정**: PNG/JPEG, 긴 변 2K(2048px)·4K(4096px) 또는 작업 크기, 파일 이름을 선택하고 정확한 크기를 확인합니다. JPEG의 투명 영역은 흰색으로 합성합니다. 작업 크기 출력은 긴 변 8192px·총 4천만 픽셀 이내로 제한합니다.
- **로컬 처리**: 사진은 서버로 전송하지 않습니다. 사진과 편집 이력은 현재 세션에 유지되므로 새로고침하거나 닫기 전에 프로젝트를 저장하세요. 가벼운 환경설정은 브라우저에 보관됩니다.

## 단축키

| 작업 | Windows / Linux | macOS |
| --- | --- | --- |
| 실행 취소 | Ctrl+Z | ⌘Z |
| 다시 실행 | Ctrl+Shift+Z 또는 Ctrl+Y | ⌘Shift+Z |
| 프로젝트 저장 | Ctrl+S | ⌘S |
| 내보내기 | Ctrl+Shift+S | ⌘Shift+S |
| 레이아웃 / 사진 / 시그니처 | 1 / 2 / 3 | 1 / 2 / 3 |
| 집중 보기 / 종료 | F / Esc | F / Esc |

텍스트 입력 중에는 기본 텍스트 편집 단축키가 우선합니다. 모바일에서도 상단 편집 이력과 저장 시트의 프로젝트·출력 기능을 사용할 수 있습니다.

## 개발 및 검증

Node.js 20.9 이상에서 실행합니다.

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
```

테스트는 편집 이력과 이미지 URL 수명, 프로젝트 왕복 변환·입력 검증·실패 정리, 캔버스 비율·출력 크기를 다룹니다. 빌드는 기존 정적 배포 방식에 맞춰 `out/`을 생성합니다.
