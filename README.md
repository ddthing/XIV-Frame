# XIV Frame

XIV Frame은 파이널판타지14(FF14) 스크린샷을 여러 장 한 장의 PNG로 묶는 브라우저 도구입니다.

## 주요 기능

* **레이아웃을 먼저 정하는 사진 배열**: 최대 4장의 스크린샷을 원하는 순서로 넣고, 가로·세로·바둑판 프레임으로 구성할 수 있습니다.
* **시그니처 만들기**: 캐릭터 이름과 서버명 등의 텍스트를 입력하고, 글꼴·위치·정렬을 조정할 수 있습니다. 사진 한 장만 넣어도 시그니처를 설정할 수 있습니다.
* **커스텀 디자인 요소**: 엠블럼이나 부대 로고를 불러와 원하는 위치에 배치할 수 있습니다. 투명 PNG를 권장합니다.
* **브라우저에서 바로 편집**: 별도 프로그램 없이 결과물을 확인하면서 사진별 크기와 위치, 캔버스 비율, 시그니처를 조정한 뒤 PNG로 저장할 수 있습니다.

## 스택

* **Core**: Next.js (App Router), React, TypeScript
* **Styling**: TailwindCSS, Shadcn UI
* **Canvas**: Konva (react-konva)
* **State**: Zustand
