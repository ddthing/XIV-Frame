複数のSSをきれいにまとめるには、効果を先に試すよりも、各画像にどの役割を持たせるかを決めることが大切です。XIV Frameで2～4枚をまとめる実際の順番を説明します。

## 1. 表示する順番を決める

1. 1枚目には全身やメインポーズなど、一番見せたい画像を選びます。
2. 2枚目以降には後ろ姿、別ポーズ、装備のクローズアップを入れます。
3. 明るさや構図が大きく違う画像を混ぜるとまとまりにくいため、似た雰囲気のSSを選びます。

## 2. 画像をアップロードして並べ替える

1. PCでは**画像ソース**、スマートフォンでは下部の**写真**を開きます。
2. 空いている画像カードをクリックして、表示したい順番でファイルを選びます。
3. **順序を入れ替え**で最初の2枚を交換します。
4. カード上の左右ボタンを使うと、隣の画像と1つずつ入れ替えられます。
5. ファイルだけを変えたいときは**変更**を使えば、レイアウトを作り直す必要はありません。

## 3. 画像枚数に合うレイアウトを選ぶ

1. PCでは**レイアウト**タブ、スマートフォンでは**レイアウト**シートを開きます。
2. 2枚を左右で比較するなら**横分割**を選びます。
3. 全身の下にディテールを置くような構成なら**縦分割**を選びます。
4. 3～4枚をコンパクトに見せるなら**グリッド配置**を選びます。3枚未満では使用できません。

## 4. キャンバス比率を選ぶ

1. まず**自動**で現在のレイアウトの大きさを確認します。
2. 標準的な横長にしたい場合は**16:9**を選びます。
3. 画像を横長の帯のようにつなげたい場合は**2:1**を選びます。
4. スマートフォンでは**保存 → 比率設定**から変更します。書き出し比率と画面のズームは別の設定です。

## 5. 画像の境界と余白を調整する

1. **トランジション**で**なし**を選ぶと、画像の間に通常の余白を作れます。
2. **画像の間隔**を0～100pxで調整し、すべての境界をそろえます。
3. 境界を重ねて自然につなぎたい場合は**ソフトブレンド**を選びます。
4. **自然な境界の幅**を少しずつ上げます。広すぎると端の装備や顔が隠れることがあります。
5. 外周に余白が必要な場合は**枠線の太さ**を加えます。

## 6. 画像ごとにトリミングを合わせる

1. カードを1枚ずつ選択します。
2. **選択中の画像**のスライダーまたは数値入力で50～300%の拡大率を設定します。
3. キャンバス上で画像をドラッグし、顔や武器など見せたい部分をフレーム内に入れます。
4. 選択中の画像の上でマウスホイールを使うと、すばやく拡大・縮小できます。
5. 位置を戻したい画像だけ**リセット**を押して、もう一度調整します。
6. 全画像の調整が終わったら**画像位置をロック**をオンにします。

## 7. 背景とオーバーレイを整える

1. 背景は**ホワイト**、**ライトグレー**、**透明**から選びます。
2. 画像の質感をそろえたい場合だけ、**フィルムノイズ**を低い値で使います。
3. 必要なら**署名 → テキスト**でキャラクター名とサーバー名を追加します。
4. FCマークは**署名 → ロゴアップロード**から追加し、被写体から離れた場所に置きます。

## 8. 保存して確認する

1. 1枚目の画像が主役として見えるか、顔や重要な装備が切れていないか確認します。
2. PCでは**PNG保存**、スマートフォンでは**保存 → 写真を保存する**を押します。
3. ダウンロードしたPNGを一度開き、端が切れていたら保存前に対象カードの拡大率と位置を調整します。
