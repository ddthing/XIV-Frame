複数のSSをまとめるときは、効果を先に試すよりフレームの形を決めてから画像を入れる方が迷いません。XIV Frameで2～4枚をまとめる手順を説明します。

## 1. フレームの形を先に決める

1. PCでは左側の**レイアウト**、スマートフォンでは下部の**レイアウト**を開きます。
2. 左右で比べるなら**横分割**、上から下へ流れを作るなら**縦分割**を選びます。
3. 3～4枚をコンパクトに見せるなら**グリッド配置**を選びます。この構成は画像が3枚以上あるときに使えます。
4. まず完成形を想像しやすい形を選び、画像を追加した後に別のレイアウトと比べても構いません。

## 2. 画像を追加して順番を整える

1. 1枚目には全身やメインポーズなど、一番見せたい画像を選びます。2枚目以降には後ろ姿、別ポーズ、装備のクローズアップを入れます。
2. **写真**を開き、空いている枠に表示したい順番で画像を追加します。
3. カードの順番移動ボタンで、画像を1つずつ前後へ動かします。
4. ファイルだけを変えたいときは**変更**を使います。画像と画像ごとの調整値を保ったまま比べられます。
5. 1ファイル50MB以下で、読み込み後はブラウザ内で自動最適化されます。

## 3. キャンバス比率を選ぶ

1. PCでは**レイアウト**パネルを開き、まず**自動**で現在のレイアウトの大きさを確認します。
2. 標準的な横長にしたい場合は**16:9**を選びます。
3. 画像を横長の帯のようにつなげたい場合は**2:1**を選びます。
4. スマートフォンでは**保存 → 比率設定**から変更します。書き出し比率と画面のズームは別の設定です。

## 4. 画像の境界と余白を調整する

1. **トランジション**で**なし**を選ぶと、画像の間に通常の余白を作れます。
2. **画像の間隔**を0～100pxで調整し、すべての境界をそろえます。
3. 境界を重ねて自然につなぎたい場合は**ソフトブレンド**を選びます。
4. **つなぎ目の幅**を少しずつ上げます。広すぎると端の装備や顔が隠れることがあります。
5. 外周に余白が必要な場合は**枠線の太さ**を加えます。

## 5. 画像ごとにトリミングを合わせる

1. カードを1枚ずつ選択します。
2. **選択中の画像**のスライダーまたは数値入力で50～300%の拡大率を設定します。
3. キャンバス上で画像をドラッグし、顔や武器など見せたい部分をフレーム内に入れます。
4. 選択中の画像の上でマウスホイールを使うと、すばやく拡大・縮小できます。
5. 位置を戻したい画像だけ**リセット**を押して、もう一度調整します。
6. 全画像の調整が終わったら**画像位置をロック**をオンにします。

## 6. 背景とオーバーレイを整える

1. 背景は**ホワイト**、**ライトグレー**、**透明**から選びます。
2. 画像の質感をそろえたい場合だけ、**フィルムノイズ**を低い値で使います。
3. 必要なら**署名 → テキスト**でキャラクター名とサーバー名を追加します。
4. FCマークは**署名 → ロゴアップロード**から追加し、被写体から離れた場所に置きます。

## 7. 保存して確認する

1. キャンバス下の表示ドックで**画面に合わせる**またはズームを使い、1枚目の画像が主役として見えるか、顔や重要な装備が切れていないか確認します。
2. PCでは**PNG保存**、スマートフォンでは**保存 → PNGで保存**を押します。
3. ダウンロードしたPNGを一度開き、端が切れていたら保存前に対象カードの拡大率と位置を調整します。
