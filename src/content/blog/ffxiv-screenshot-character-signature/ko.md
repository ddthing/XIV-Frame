시그니처는 스크린샷 위에 캐릭터 이름과 서버명처럼 짧은 정보를 올리는 텍스트 레이어입니다. 사진을 가리지 않으면서도 누가 만든 이미지인지 남기고 싶을 때 사용하세요.

## 1. 시그니처 설정을 엽니다

1. 사진을 먼저 하나 이상 업로드합니다. 사진이 있어야 캔버스에서 결과를 확인하기 쉽습니다.
2. 데스크톱 오른쪽 패널에서 **시그니처** 탭을 엽니다.
3. 모바일에서는 하단 메뉴의 **서명**을 누릅니다.
4. 기본으로 **텍스트** 탭이 열립니다. 로고를 넣을 때는 같은 화면의 **로고 업로드** 탭을 사용합니다.

## 2. 두 줄의 텍스트를 입력합니다

1. **상단 텍스트**에 캐릭터 이름을 입력합니다. 예를 들어 `Luna`처럼 짧은 이름을 넣습니다.
2. **하단 텍스트**에는 서버명, 자유부대명, 계정명처럼 보조 정보를 입력합니다.
3. 각 입력 칸은 최대 30자입니다. 문장이 길어지면 시그니처가 사진을 가릴 수 있으므로 핵심 정보만 남깁니다.
4. 입력 즉시 캔버스의 두 줄 텍스트가 바뀌는지 확인합니다.

## 3. 각 줄의 스타일을 따로 조정합니다

1. 상단 텍스트와 하단 텍스트에는 각각 **굵게**와 **기울임** 버튼이 있습니다.
2. 캐릭터 이름은 굵게, 서버명은 보통 굵기로 두면 정보의 우선순위가 분명해집니다.
3. **자간** 슬라이더는 -10px부터 20px까지 조정합니다. 짧은 영문 이름은 자간을 조금 넓히고, 한글 이름은 기본값에 가깝게 두는 것이 읽기 쉽습니다.

## 4. 위치와 정렬을 맞춥니다

1. **위치**의 9칸 버튼에서 좌상단·우상단·좌하단·우하단·정중앙 등을 선택합니다.
2. 인물의 얼굴이나 중요한 장비가 있는 곳은 피해서 배치합니다.
3. **정렬**에서 왼쪽·가운데·오른쪽 정렬을 선택합니다. 두 줄을 한 덩어리처럼 보이게 하려면 위치와 정렬을 같은 방향으로 맞춥니다.
4. 하단 모서리에 배치할 때는 이미지의 밝은 부분과 겹치지 않는지 확인합니다. 겹친다면 색상과 불투명도를 먼저 조정합니다.

## 5. 글꼴과 전체 크기를 조정합니다

1. **글꼴** 선택 메뉴를 열고 미리보기에서 글자 모양을 비교합니다.
2. 기본 글꼴은 **Pretendard**입니다. 작은 화면에서도 이름과 서버명이 선명하게 보이도록 설정되어 있습니다.
3. 장식적인 결과를 원하면 다른 글꼴을 선택하되, 이름과 서버명이 작게 뭉개지지 않는지 확인합니다.
4. **크기** 슬라이더는 50~200% 범위입니다. 긴 이름은 크기를 낮추고 짧은 이름은 조금 키웁니다.

## 6. 색상과 불투명도를 맞춥니다

1. **색상**을 눌러 글자 색을 선택합니다.
2. 밝은 배경에는 검정이나 짙은 색, 어두운 배경에는 흰색이나 밝은 색을 사용합니다.
3. **불투명도**는 0~100% 범위입니다. 워터마크처럼 은은하게 남기려면 60~85%부터 확인합니다.
4. 읽기 어려울 정도로 낮추지 말고, 사진의 주제가 먼저 보이는 선에서 멈춥니다.

## 7. 저작권 오버레이를 설정합니다

1. 텍스트 설정 아래 **저작권 오버레이**의 **저작권 표시** 스위치를 확인합니다. 서비스가 제공하는 저작권 문구를 캔버스에 함께 표시할 때 켭니다.
2. 문구 자체는 직접 입력하거나 편집할 수 없습니다. 표시 여부와 위치·색상만 조정할 수 있습니다.
3. **저작권 위치**에서 **좌측**, **중앙**, **우측** 중 하나를 선택합니다.
4. **저작권 색상**에서 **검정색**, **흰색**, **회색** 중 하나를 선택하고, 사진과 충분히 대비되는지 확인합니다.

## 8. 저장 전에 최종 확인합니다

1. 사진을 100%에 가까운 미리보기로 확인합니다.
2. 이름의 첫 글자와 서버명이 잘리지 않았는지 확인합니다.
3. 사진의 얼굴·무기·의상 문양 위에 텍스트가 겹치면 위치 버튼으로 옮깁니다.
4. 저작권 표시를 켰다면 하단의 고정 문구가 사진과 겹치거나 너무 흐리지 않은지 확인합니다.
5. 데스크톱 상단의 **저장 PNG**, 모바일 **저장 → 사진 저장하기**를 눌러 결과를 다운로드합니다. PNG를 우선 저장하지만, 5MB를 넘는 불투명 결과는 고화질 JPEG로 자동 저장됩니다. 투명 PNG를 5MB 이하로 만들 수 없으면 안내가 표시됩니다.

시그니처와 레이아웃 설정은 브라우저에 로컬로 저장됩니다. 다음 작업에서도 같은 스타일을 사용하고 싶다면 같은 브라우저에서 작업을 이어가세요.
