署名は、スクリーンショットの上にキャラクター名やサーバー名を2行で重ねるテキストレイヤーです。別の画像編集ソフトを使わずに、自分の作品だと分かる情報を残せます。

## 1. 署名設定を開く

1. まずSSを1枚以上アップロードし、実際の画像を見ながら調整できるようにします。
2. PCでは右側の**署名**、スマートフォンでは下部メニューの**署名**を開きます。
3. 最初は**テキスト**タブが表示されます。画像ロゴを追加するときは**ロゴアップロード**を選びます。

## 2. 2行のテキストを入力する

1. **上部テキスト**にキャラクター名を入力します。
2. **下部テキスト**にサーバー名や補足のラベルを入力します。
3. 各入力欄は最大30文字です。短い名前のほうが画像を邪魔せず読みやすくなります。
4. 入力するとキャンバス上の文字がすぐに更新されます。

## 3. 行ごとのスタイルを決める

1. 各テキスト欄の**太字**と**斜体**は個別に切り替えられます。
2. キャラクター名を太字、サーバー名を通常にすると情報の階層が分かりやすくなります。
3. **文字間隔**は各行ごとに調整できます。狭すぎる文字や広がりすぎた文字をプレビューで確認します。

## 4. 位置と整列を合わせる

1. **位置**の9つのボタンから、左上・右上・中央・左下・右下などを選びます。
2. **整列**で左揃え、中央揃え、右揃えを選びます。
3. 顔、手、武器、装備の模様など重要な部分に重ならない位置を選びます。
4. 背景と文字が重なって読みにくい場合は、文字を大きくする前に位置を変えてみます。

## 5. フォントとサイズを選ぶ

1. **フォント**を開き、実際の画像上で各フォントを比較します。
2. 標準フォントは**Pretendard**です。小さな画面でも名前とサーバー名を読みやすく表示できます。
3. 装飾的なフォントを使う場合も、キャラクター名とサーバー名が読めるかを確認します。
4. **サイズ**は50～200%の範囲です。長い名前は小さく、余白がある場合だけ少し大きくします。

## 6. 色と不透明度を調整する

1. **色**を開き、背景とのコントラストが取れる色を選びます。
2. 明るい背景には濃い色、暗い背景には白や明るい色が見やすくなります。
3. **不透明度**は0～100%です。控えめな透かしなら60～85%から試します。
4. 文字が読めないほど薄くせず、写真の主役を邪魔しない範囲で調整します。

## 7. 著作権オーバーレイを設定する

1. テキスト設定の下にある**著作権オーバーレイ**で、**著作権表記を表示**をオン・オフします。
2. 表示される文言はアプリが用意した固定文言で、自由に入力することはできません。表示、位置、色だけを変更できます。
3. **著作権の位置**で**左**、**中央**、**右**を選びます。
4. **著作権の色**で**黒**、**白**、**グレー**を選び、画像下部とのコントラストを確認します。

## 8. 結果ファイルを保存する

1. 文字の最初と最後が切れていないか、被写体に重なっていないか確認します。
2. 著作権表示をオンにした場合は、固定文言が見えているか、背景に埋もれていないか確認します。
3. PCでは右上の**PNG保存**をクリックします。
4. スマートフォンでは**保存**を開き、**写真を保存する**をタップします。
5. 文字が強すぎる場合は、保存前に位置や不透明度を戻して調整します。
6. PNGを優先しますが、5MBを超える不透明な結果は高画質JPEGとして保存されます。透明PNGを5MB以下にできない場合は保存されず、案内が表示されます。
