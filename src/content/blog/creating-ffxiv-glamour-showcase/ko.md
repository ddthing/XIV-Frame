룩덕 쇼케이스는 한 장의 멋진 사진보다 **구성의 역할이 나뉜 여러 장의 사진**이 더 많은 정보를 전달합니다. 아래 예시는 앞모습·뒷모습·전신·장비 디테일을 3~4장으로 보여주는 작업 순서입니다.

## 1. 사진의 역할을 먼저 나눕니다

1. 첫 번째 사진은 전체 실루엣이 잘 보이는 대표 컷으로 정합니다.
2. 두 번째 사진은 뒷모습이나 옆모습처럼 의상의 다른 면을 보여주는 컷으로 고릅니다.
3. 세 번째 사진은 얼굴, 무기, 장식처럼 가까이 보여줄 디테일 컷으로 정합니다.
4. 네 번째 사진을 사용할 수 있다면 포즈가 가장 강한 장면이나 염색 색상을 확인할 수 있는 컷을 추가합니다.
5. 사진마다 밝기와 색감이 크게 다르면 레이아웃을 맞춰도 하나의 세트처럼 보이지 않으므로, 먼저 사용할 사진을 추립니다.

## 2. 사진을 순서대로 업로드합니다

1. 데스크톱 오른쪽 **이미지 소스**, 모바일 하단 **사진**에서 이미지를 추가합니다.
2. 대표 컷을 이미지 1, 뒷모습을 이미지 2, 디테일을 이미지 3 순서로 올립니다.
3. 사진은 최대 16장, 한 장당 50MB 이하입니다. 3×3·4×4 격자를 쓰려면 각각 9장·16장을 준비합니다. 큰 원본은 업로드 후 브라우저에서 자동 최적화됩니다.
4. 순서가 마음에 들지 않으면 **순서 바꾸기**나 카드의 좌우 이동 버튼으로 수정합니다.

## 3. 바둑판 레이아웃을 선택합니다

1. 데스크톱 **레이아웃** 탭 또는 모바일 하단 **레이아웃** 메뉴를 엽니다.
2. 사진이 3~4장이면 **바둑판 배치**를 선택합니다. 2×2 네 칸을 사용하며, 세 장이면 한 칸이 비어 있고 네 장이면 모두 채워집니다.
3. 사진이 두 장뿐이면 **가로 분할**이나 **세로 분할**을 선택합니다. 두 장으로 억지로 바둑판을 만들 필요는 없습니다.
4. 배치가 바뀌면 각 사진을 다시 선택해 얼굴과 의상 디테일이 잘리는지 확인합니다.

## 4. 쇼케이스에 맞는 비율을 정합니다

1. 기본값인 **원본 비율**로 먼저 자연스러운 전체 구도를 확인합니다.
2. 16:9 가로형 쇼케이스가 필요하면 **X 타임라인**을 선택합니다.
3. 사진을 길게 이어 포스터나 배너처럼 보여주려면 **2:1**을 선택합니다.
4. 모바일에서는 **저장 → 비율 설정**에서 비율을 선택합니다. 하단 **레이아웃** 메뉴는 배치와 연결 효과를, **저장** 메뉴는 저장 비율을 담당합니다.

## 5. 각 칸의 크롭과 위치를 맞춥니다

1. 이미지 카드를 눌러 대표 컷부터 선택합니다.
2. **선택한 이미지** 배율을 조정해 인물의 머리와 발끝이 적절히 보이게 합니다.
3. 캔버스에서 이미지를 드래그해 시선이 향하는 방향과 빈 공간을 맞춥니다.
4. 얼굴이나 무기처럼 보여주고 싶은 디테일이 잘리지 않도록 배율을 50~300% 범위에서 조정합니다.
5. 모든 칸을 맞춘 뒤 **캔버스 이미지 위치 잠금**을 켜면 최종 확인 중 실수로 사진이 움직이지 않습니다.

## 6. 여백과 배경을 통일합니다

1. 사진 사이 간격은 **이미지 간격**으로 맞춥니다. 쇼케이스는 0에 가깝게 붙이거나, 일정한 여백을 두는 두 방향 모두 가능합니다.
2. 사진 경계를 부드럽게 연결하고 싶다면 **자연스럽게**를 선택하고, 겹치는 영역 너비를 조금씩 조정합니다.
3. **테두리 두께**를 추가하면 각 사진이 분리되어 보입니다.
4. 배경은 화이트나 연한 회색부터 비교합니다. 의상이 밝으면 연한 회색이 경계를 만들기 쉽습니다.
5. 필름 노이즈는 모든 사진의 질감을 통일하고 싶을 때만 낮은 값으로 사용합니다.

## 7. 이름과 로고를 배치합니다

1. **시그니처 → 텍스트**에서 캐릭터 이름과 서버명을 입력합니다.
2. 텍스트는 대표 컷의 얼굴과 겹치지 않는 위치에 둡니다.
3. 자유부대나 브랜드 로고가 있다면 **시그니처 → 로고 업로드**에서 추가합니다.
4. 텍스트와 로고가 같은 구석에 모이지 않도록 위치를 나눕니다.

## 8. 저장 전 체크리스트

- 대표 컷이 가장 먼저 보이는가
- 모든 사진에서 얼굴과 의상 디테일이 잘리지 않았는가
- 사진 사이 간격과 바깥 테두리가 일정한가
- 이름·서버명·로고가 서로 겹치지 않는가
- 배경과 글자 색의 대비가 충분한가

확인이 끝나면 데스크톱의 **저장 PNG**, 모바일의 **저장 → 사진 저장하기**를 눌러 쇼케이스 이미지를 다운로드합니다. PNG가 5MB를 넘는 불투명 결과는 고화질 JPEG로 자동 최적화됩니다.
