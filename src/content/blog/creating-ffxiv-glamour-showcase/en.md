A useful glamour board gives every image a job. The example below uses a front view, a back or side view, a full-body pose, and a close-up detail so the outfit can be understood at a glance.

## 1. Choose the four roles

1. Use the first image for the strongest full-body or hero pose.
2. Use the second image for the back, side, or silhouette.
3. Use the third image for a face, weapon, accessory, or dye detail.
4. Use the fourth image for another pose or a detail that would otherwise be missed.
5. Remove shots with very different lighting or framing before you start arranging them.

## 2. Upload in viewing order

1. Open **Image source** on desktop or **Photo** on mobile.
2. Upload the hero image first, then the alternate view and detail shots.
3. You can use up to four images, with a 10MB limit for each file.
4. Use **Swap Order** or the card movement controls if the story of the images is not clear.

## 3. Choose the layout

1. Open **Layout** on desktop or the mobile **Layout** sheet.
2. Choose **Grid** when you have three or four images and want a compact board.
3. Choose **Split** or **Vertical** when you have only two images. Grid requires at least three images.
4. Recheck the crop after changing the layout because each image receives a new frame area.

## 4. Set the ratio

1. Start with **Auto** to inspect the natural composition.
2. Choose **16:9** for a familiar wide showcase canvas.
3. Choose **2:1** for a long banner-like result.
4. On mobile, use **Export → Ratio Settings**. The export ratio is separate from preview zoom.

## 5. Correct every frame

1. Select the hero image card and set its scale first.
2. Drag each image on the canvas so the face, silhouette, and outfit details remain visible.
3. Use the 50–300% scale control for close-ups or wide shots that need different framing.
4. Use **Reset** on an individual image if its crop becomes difficult to recover.
5. Turn on **Lock Image Position** after all four frames are aligned.

## 6. Make the board feel consistent

1. Use **Image Gap** to create either a clean seam or a deliberate amount of breathing room.
2. Use **Soft Blend** only when overlapping edges help the composition; lower the blend width if details disappear.
3. Add a small **Border Width** when the board needs a clear outer edge.
4. Choose a background that separates the outfit from the canvas. Light Gray is useful when both the UI and the outfit contain a lot of white.
5. Keep **Film Grain** at 0% or use a low value so it does not compete with fabric details.

## 7. Add the identity layer

1. Open **Signature → Text** and enter the character name and server label.
2. Place the text in an empty area of the hero frame instead of covering the face.
3. Add a Free Company mark from **Signature → Logo Upload** only if the board still has enough visual space.
4. Put the text and logo in different areas and lower opacity when both overlays feel heavy.

## 8. Final checklist and export

- Does the first frame work as the visual entry point?
- Are the face, silhouette, weapon, and outfit details visible in every cell?
- Are the gaps and outer border consistent?
- Are the name, server, and logo separate from the main subject?
- Is the text contrast strong enough at the size where you will post it?

When the checklist is clear, click **Save PNG** on desktop or **Export → Save Photo** on mobile.
