ミラプリ紹介画像は、1枚の写真だけでなく、複数のSSにそれぞれ役割を持たせると装備の魅力が伝わります。前から見た姿、後ろ姿、全身、アクセサリーの細部を1枚にまとめる例で説明します。

## 1. レイアウトと画像の役割を決める

1. PCでは左側、スマートフォンでは下部の**レイアウト**を開き、先に**グリッド配置**を選びます。
2. 1枚目は全身のシルエットが分かるメインポーズにします。
3. 2枚目は後ろ姿や横向きなど、別の角度を見せるSSにします。
4. 3枚目は顔、武器、アクセサリーなどのクローズアップにします。
5. 4枚目を使う場合は、別ポーズや染色の色が分かるSSを選びます。
6. 明るさや構図が大きく異なる画像は、先に候補から外すと全体がまとまりやすくなります。

## 2. 表示順でアップロードする

1. **写真**を開き、表示する順番で画像を追加します。
2. メインポーズ、別角度、細部の順番でカードに画像を追加します。
3. 画像は最大4枚、1枚50MB以下です。大きな元画像はアップロード後、ブラウザ内で自動最適化されます。
4. 順番が分かりにくい場合は、カードの順番移動ボタンで1つずつ調整します。

## 3. 画像を入れた後に配置を確認する

1. 3～4枚なら**グリッド配置**で、4枚すべての枠が埋まることを確認します。
2. 2枚だけなら**横分割**または**縦分割**に変えます。画像が2枚なのにグリッドにする必要はありません。
3. レイアウトを変えた後は、各画像の切り取られ方をもう一度確認します。

## 4. 比率を設定する

1. PCでは**レイアウト**パネルを開き、まず**自動**で全体の配置を確認します。
2. 標準的な横長の紹介画像なら**16:9**を選びます。
3. 横長のバナーのように見せたい場合は**2:1**を選びます。
4. スマートフォンでは**保存 → 比率設定**から変更します。書き出し比率とプレビューズームは別の設定です。

## 5. 各フレームの構図を整える

1. まずメインポーズのカードを選び、サイズを決めます。
2. キャンバス上で画像をドラッグし、顔、シルエット、衣装の細部が見える位置に移動します。
3. 50～300%のサイズ設定で、全身のSSとクローズアップの見え方をそれぞれ調整します。
4. 位置を戻したい場合は、その画像だけ**リセット**します。
5. すべてのフレームを合わせたら**画像位置をロック**をオンにします。

## 6. 全体の余白をそろえる

1. **画像の間隔**でフレーム間の余白をそろえます。
2. 境界を重ねたい場合だけ**ソフトブレンド**を使い、細部が消えたら**つなぎ目の幅**を下げます。
3. 外側の印象を整えたい場合は**枠線の太さ**を少し加えます。
4. 背景は**ホワイト**または**ライトグレー**から比較します。
5. **フィルムノイズ**は衣装の質感を邪魔しない低い値にします。

## 7. 名前とロゴを配置する

1. **署名 → テキスト**でキャラクター名とサーバー名を入力します。
2. メインポーズの顔に重ならない場所へ署名を置きます。
3. FCマークは**署名 → ロゴアップロード**から追加します。
4. 文字とロゴを別の場所に分け、不透明度を下げても主役が見えるようにします。

## 8. 保存前のチェック

- 1枚目がメイン画像として見えるか
- 各フレームで顔、シルエット、武器、衣装の細部が切れていないか
- 画像の間隔と外周の余白がそろっているか
- 名前、サーバー、ロゴが被写体に重なっていないか
- 小さく表示しても文字のコントラストが足りているか

確認できたら、PCでは**PNG保存**、スマートフォンでは**保存 → PNGで保存**を押します。
