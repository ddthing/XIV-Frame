프레임을 예쁘게 만드는 것과 게시할 준비가 끝난 것은 같은 일이 아닙니다. 게시물에 포함된 게임 화면, 캐릭터 이름, 로고, 다른 사람의 캐릭터가 각각 어떤 권리와 맥락을 가지는지 확인해야 합니다. 이 글은 법률 자문이 아니라, XIV Frame에서 결과 파일을 저장하기 직전에 놓치기 쉬운 항목을 점검하는 작업 기준입니다.

## 1. 내가 사용할 권리가 있는 이미지인지 확인합니다

1. 직접 촬영한 스크린샷인지, 다른 사람이 촬영한 이미지를 허락받았는지 확인합니다.
2. 파티원이나 지인의 캐릭터가 포함되었다면 게시 범위에 대한 동의를 확인합니다. 게임 안에서 함께 촬영했다는 사실만으로 외부 게시 동의가 자동으로 생기는 것은 아닙니다.
3. 자유부대 마크, 커뮤니티 로고, 다른 창작자의 PNG를 올릴 때는 사용 조건과 출처 요구를 확인합니다.
4. 게임 콘텐츠와 상표는 각 권리자의 자산입니다. XIV Frame을 사용했다는 이유로 게임 이미지나 로고의 권리가 바뀌지는 않습니다.

XIV Frame은 Square Enix와 제휴하거나 공식 승인된 서비스가 아닙니다. 게시물 설명에 공식 서비스처럼 보이는 문구를 넣지 말고, 필요한 경우 게임과 로고의 출처 또는 권리자 안내를 함께 적으세요.

## 2. 이미지 안의 개인정보를 살핍니다

스크린샷은 게임 화면이지만, 채팅창·친구 목록·서버명·캐릭터 이름·커뮤니티 알림이 함께 찍힐 수 있습니다.

- 채팅창에 다른 이용자의 이름이나 대화 내용이 남아 있지 않은가
- 캐릭터 이름·서버명이 공개되어도 괜찮은가
- 디스코드, SNS, 스트리밍 도구의 알림이나 계정명이 포함되지 않았는가
- 로고나 시그니처가 다른 사람의 이름을 가리지 않거나 잘못된 정보처럼 보이지 않는가

필요하다면 원본을 다시 촬영하거나, XIV Frame에서 사진의 위치와 배율을 조정해 불필요한 영역을 캔버스 밖으로 보냅니다. 다만 가려졌다고 생각한 영역이 저장 결과에 남지 않았는지 최종 결과 파일을 직접 열어 확인해야 합니다.

## 3. 시그니처와 저작권 표시를 구분합니다

시그니처는 캐릭터 이름, 서버명, 계정명처럼 이용자가 입력하는 정보입니다. 저작권 표시는 결과물에 서비스 또는 권리 안내를 남기기 위한 별도 오버레이입니다. 둘을 같은 위치에 겹치면 어떤 정보가 무엇을 의미하는지 알아보기 어렵습니다.

1. **시그니처 → 텍스트**에서 상단·하단 텍스트의 의미를 먼저 정합니다.
2. 이름과 서버명을 한쪽 모서리에 배치했다면 로고나 저작권 표시는 다른 영역에서 시작합니다.
3. 작은 사진에서는 글자를 크게 키우기보다 불투명도를 낮추고, 중요한 정보와 겹치지 않는 위치를 선택합니다.
4. 최종 결과에 서비스 저작권 표시가 필요한지 확인하고, 필요하지 않으면 표시를 끈 상태와 켠 상태를 비교합니다.

표시가 많아질수록 신뢰도가 올라가는 것은 아닙니다. 한 장에서 읽혀야 할 정보의 우선순위를 정한 뒤 가장 적은 레이어로 목적을 달성하세요.

## 4. 합성 요소의 경계를 확인합니다

배경 제거한 캐릭터나 빛·이펙트 PNG는 전체 분위기를 바꾸지만, 가장자리가 부자연스러우면 결과물의 신뢰도가 빠르게 떨어집니다.

1. 100% 미리보기에서 외곽선에 원래 배경색이 남아 있는지 확인합니다.
2. 필요한 대상이 함께 지워졌다면 복원 브러시로 되살립니다.
3. 그림자가 발밑이나 접점과 맞지 않으면 끄거나 투명도를 낮춥니다.
4. 합성 요소가 얼굴, 손, 무기처럼 원근을 판단하는 부분을 가리지 않는지 확인합니다.
5. 배경 제거가 어려운 이미지라면 자동 결과를 그대로 게시하지 말고, 보정 후에도 자연스럽지 않은 경우 해당 요소를 빼는 선택을 합니다.

## 5. 읽을 수 있는 텍스트를 남깁니다

텍스트는 장식이 아니라 정보입니다. 다음 조건을 모두 만족할 필요는 없지만, 게시 대상과 배경에 맞춰 최소한의 가독성을 확보해야 합니다.

- 이름과 서버명이 사진의 밝은 부분에 묻히지 않는가
- 작은 화면에서도 첫 글자와 마지막 글자가 잘리지 않는가
- 자간을 과하게 넓혀 단어가 분리되어 보이지 않는가
- 불투명도를 낮췄을 때도 읽어야 하는 정보가 남아 있는가
- 로고와 텍스트가 같은 모서리에 몰려 시선이 막히지 않는가

가독성이 부족하면 글자 크기만 키우기보다 위치, 색상, 불투명도 순서로 조정합니다. 사진의 주제가 먼저 보이고, 필요한 정보가 두 번째로 읽히는 구성이 일반적으로 안정적입니다.

## 6. 저장한 결과를 실제 파일로 검수합니다

미리보기와 다운로드 파일이 항상 같은 방식으로 보인다고 가정하지 마세요. 저장 후 결과 파일을 직접 열어 다음을 확인합니다. PNG를 우선 저장하지만, 5MB를 넘는 불투명 결과는 고화질 JPEG로 저장될 수 있으므로 파일 확장자도 함께 확인합니다.

1. 캔버스의 네 모서리가 잘리지 않았는지 확인합니다.
2. 투명 배경을 선택했다면 투명 영역이 의도대로 남았는지 확인합니다.
3. 글자와 로고가 화면 밖으로 밀리지 않았는지 확인합니다.
4. 배경 제거 경계, 그림자, 필름 노이즈가 과하게 보이지 않는지 확인합니다.
5. 게시용 사본의 파일 크기와 이미지 크기가 게시 서비스의 제한을 넘지 않는지 확인합니다.

## 게시 전 10초 점검표

- [ ] 이미지와 로고의 사용 권리를 확인했다.
- [ ] 다른 사람의 캐릭터·이름·대화가 포함되었는지 확인했다.
- [ ] 공식 서비스로 오해할 만한 표현을 사용하지 않았다.
- [ ] 시그니처와 저작권 표시가 서로 겹치지 않는다.
- [ ] 합성 요소의 외곽선과 그림자가 자연스럽다.
- [ ] 이름·서버명·로고가 작은 화면에서도 읽힌다.
- [ ] 중요한 얼굴·장비·텍스트가 가려지지 않는다.
- [ ] 저장된 결과 파일(PNG 또는 JPEG)을 직접 열어 가장자리를 확인했다.
- [ ] 게시 서비스의 파일 용량 제한을 확인했다.
- [ ] 원본과 게시용 결과물을 따로 보관했다.

이 점검표는 특정 플랫폼의 규칙을 대신하지 않습니다. 게시하려는 커뮤니티, SNS, 게임 운영정책의 최신 안내가 있다면 그 기준을 우선 확인하세요. XIV Frame에서는 게시 직전의 확인을 돕고, 이미지의 권리와 게시 책임을 대신 판단하지 않습니다.
